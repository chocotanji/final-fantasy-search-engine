# Final Fantasy Search Engine

The context for this project is [MoogleAPI](https://github.com/jackfperryjr/moogleapi), a REST API that provides data about the *Final Fantasy* franchise, including games, characters, and monsters. This project explores how API data can be used to build a searchable website that helps users discover content across the franchise.

## Client-Side Search and API Integration

APIs provide data that can be displayed and organised on a website. Some APIs offer dedicated search endpoints, while others allow developers to retrieve a list of items and filter the results on the client side using JavaScript. MoogleAPI provides search endpoints for characters and monsters, allowing users to search for specific entries by name or description. For games, the website can retrieve the available list and filter the results using JavaScript's `.filter()` method.

## MoogleAPI

MoogleAPI provides information about *Final Fantasy* games, characters, and monsters through REST endpoints. This project uses HTML, CSS, and JavaScript to retrieve the data, display search results, and provide category and game filters. The goal is to create an accessible and user-friendly search experience that makes it easier to explore the franchise.
